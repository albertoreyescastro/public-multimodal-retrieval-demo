How it works

A deliberately generic retrieval pipeline

1 Images Public samples or local uploads
→
2 Vision encoder CLIP image embeddings
→
3 In-memory index Normalised vectors for this session
→
4 Text query CLIP text embedding + cosine ranking

This demo is an independent implementation using a standard public CLIP model. It contains no TeachScribe source code, assets, UI, data, or private implementation details.

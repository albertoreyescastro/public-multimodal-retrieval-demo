# Privacy handling

This repository is an evidence-focused public case study. It deliberately excludes the application source code and user data while retaining architecture, measurements and de-identified engineering evidence.

| Category | Public treatment |
| :-- | :-- |
| Classroom photos, gallery screenshots, thumbnails | not included |
| Media IDs, filenames, URIs and exact capture dates | not included |
| Evaluation images and linked per-query records | kept outside this repository; aggregate/de-identified results only |
| Device identifiers and personal filesystem paths | not included |
| Application source code and native implementation | not included |
| Model binaries, APKs and signing material | not included |
| Diagnostic payloads | no real observation text, photo identifiers, filenames, URIs or image data are published |

The temporal evidence uses relative labels such as `D0` and `D-3`. Numeric benchmark files retain engineering measurements but do not include the underlying private image dataset.

Any future screenshot, log, dataset or device export should receive a fresh privacy review before publication.
